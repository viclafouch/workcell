# The dashboard

Open the dashboard in your browser to see what each robot does right now, without asking anyone in the chat.

## What the page shows

1. **Who works now**: each robot on a task, what it works on, and how much of its budget it spent.
2. **Who waits for you**: the robots that stopped to ask a person, named at the top of the page.
3. **One robot at a time**: open a robot to follow its plan, each command it runs with its result, and each file it changes, as it happens.
4. **What it finished lately**: each task with how it ended and what it cost.
5. **What got in their way**: the notes the robots send about a tool or a rule that blocked them.

## Your look, not ours

The page wears the colors, the fonts and the logo of your team. Hand them to the developer who runs the agent, and the next start shows them.

## What the dashboard never does

- It never starts, steers or stops a robot: that stays in the chat, where the agent checks who asks.
- It never opens a terminal into a robot's closed box.
- It never reads the memory of the agent behind its back: it asks the agent, like the chat does.
- It never leaves the computer that runs the agent: only that computer can open it.

## Try it

Start a small task in the chat, then open the dashboard and watch the robot write its plan.
